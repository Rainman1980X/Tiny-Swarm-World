# RC1-R01 Remaining Risks

- A qualified and explicitly authorized WSL2 target is required to observe the
  update, rollback and post-update acceptance path.
- A qualified and explicitly authorized native-Linux target is required for
  cross-host evidence.
- The protected self-hosted Classic runner must consume the same command and
  publish redacted evidence before the issue can be accepted.
- The exact externally analyzed candidate remains unknown until the branch is
  integrated and the external gate is observed.
