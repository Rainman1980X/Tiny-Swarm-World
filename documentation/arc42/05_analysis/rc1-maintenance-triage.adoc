== Bounded follow-up

Create one post-RC1 issue titled *Extract LXC resource qualification adapter*.
Affected files are
infrastructure/adapters/clients/lxc_node_provider.py and the existing
infrastructure/adapters/clients/lxc/resource package. Preserve
PortNodeLifecycle, ProviderSelection and VerificationResult contracts.
Regression coverage must include supported/unsupported resource resolution,
capacity rejection, provider lifecycle success, provider failure propagation
and redacted evidence. The expected benefit is smaller provider changes with
the same safety and evidence behavior.

No observation in this review is promoted to an RC1 release blocker.
